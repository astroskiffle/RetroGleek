Modifications made for RetroGleek (RECOIL.cs)
-------------------------------------------
RECOIL.cs is NOT the unmodified upstream output. It is produced by tools/downgrade_recoil.py, which:
  1. translates recoil.fu to C# with the "fut" translator (https://github.com/fusionlanguage/fut; the
     translator itself is not part of RetroGleek),
  2. rewrites the result to C# 5 syntax so it builds with the C# compiler that ships with Windows
     (removes `#nullable` and nullable annotations, removes the null-forgiving operator, converts
     expression-bodied members to block bodies). Only code is rewritten: every string literal, character
     literal and comment is verified to be identical to the translator's output,
  3. lowers RECOIL's allocation cap from 134217728 to 16777216 pixels/bytes at all six places it occurs,
  4. appends the RetroFormats extension tables taken from RECOIL's formats.xml.

Reproducing / verifying RECOIL.cs
---------------------------------
  python3 tools/downgrade_recoil.py <path-to-recoil-checkout> RECOIL.cs        (needs `fut` on PATH or FUT=...)

To check that the whole program still parses as C# 5 (the language level of the compiler built into
Windows), compile it with a Roslyn csc pinned to that version, for example:
  csc -langversion:5 -target:winexe Program.cs RECOIL.cs  (plus the usual /reference: assemblies)
Re-run this check, and re-test, whenever RECOIL.cs is regenerated from a newer RECOIL.

Network / privacy
-----------------
RECOIL.cs contains no networking, process-launching, registry, reflection or unsafe/native code. The only
files it ever opens on its own are companion files (palettes, colour maps) of the picture being decoded,
and RetroGleek restricts those to the picture's own folder and refuses cloud placeholder files.
